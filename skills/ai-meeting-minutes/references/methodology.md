# AI 会议分析方法

## 使用原则

方法是内部思考工具，不是输出目录。每次只选择会提高当前会议判断质量的最少组合；普通同步会不套重型决策框架。

## 按会议类型选择

| 会议类型 | 优先方法 | 重点检查 |
|---|---|---|
| 信息同步 | 关键因素过滤、行动闭环 | 变化、阻塞、负责人 |
| 问题诊断 | 论证图、根因追问 | 根因、证据、验证动作 |
| 方案评审 | Working Backwards、决策质量 | 目标、选项、取舍 |
| 正式决策 | 单向门/双向门、异议与承诺 | 决定、条件、保留意见 |
| 项目或经营复盘 | 输入指标、假设迭代、轻量 Pre-mortem | 偏差、学习、纠偏 |
| 战略研讨 | Working Backwards、红队挑战、决策推进 | 战略选择、资源取舍、停止清单 |
| 创意讨论 | Working Backwards、选项比较 | 用户结果、候选方向 |

## 方法卡

### Working Backwards

从最终服务对象和理想结果向后检查：

1. 谁会因这个决定受益或受损？
2. 要改变的具体结果是什么？
3. 当前方案能否产生该结果？
4. 还缺少什么能力、条件或验证？

内部事务可以把“客户”替换为最终使用者或承接者。

### 书面叙事

先重建“问题—证据—选项—取舍—决定”，再压缩为要点，不把逐字稿切碎后重新排列。

亚马逊六页叙事和静默阅读主要改善会前输入质量，不应机械复制为六页会后纪要。若参会人反复解释背景或理解不一，可以建议下次会前提供短叙事材料；本次纪要仍保持精炼。

### 单向门与双向门

- **双向门**：可低成本回退，适合小步试验和快速决定。
- **单向门**：难以撤回或代价高，需要更强证据、替代方案和风险控制。

不要让可逆决定被过度分析，也不要让不可逆决定在信息不足时仓促通过。

### 异议与承诺

保留真实异议，不把不同意见模糊成“已达成一致”。决定形成后，明确保留意见、执行承诺，以及什么新证据会触发重新评估。

### 可控输入指标

除最终结果外，寻找团队可直接改变、能领先反映结果的输入指标。只在用户要求规划或复盘时扩展为独立章节。

### 论证图

只分析最多三个决定性主张：

- **主张**：会议认为事实是什么或应该做什么；
- **证据**：什么数据、经验或文件支持；
- **假设**：证据到结论依赖什么未明说的前提；
- **反例**：什么情况会让结论不成立。

### 决策质量检查

检查目标、真实选项、证据、关键取舍、不确定性、可逆性和授权人。没有比较替代方案时，不直接说决定错误；指出“尚未证明当前方案优于其他方案”。

### 轻量 Pre-mortem

只用于有明确计划或重大执行风险的会议。假设方案已经失败，找出最可能的 1–3 个原因，并转成早期信号、预防动作和应急动作。

### 行动闭环

行动项尽量包含唯一负责人、完成时间、可见交付物和验收标准。依赖外部团队时补充前置条件；避免多人共同负责却无人最终负责。

### 假设迭代

仅在用户要求复盘且存在历史基线时使用：

- **保留**：仍被事实支持；
- **修正**：方向保留，但路径、资源、目标或条件变化；
- **推翻**：已被反证，应停止或重新选择；
- **仍需验证**：缺少决定性证据，转成验证动作。
